12. Qual sintaxe representa uma maneira válida de compilar uma classe Java ?
A. java MainClass.class
B. javac MainClass
C. javac MainClass.source
D. javac MainClass.java

Resposta - Henrique: D.
As demais opções estão incorretas porque a letra A é a sintaxe para executar uma classe Java,
a letra B é uma sintaxe incorreta para compilar uma classe Java, e a letra C é uma sintaxe incorreta para
compilar uma classe Java, já que os arquivos de fonte Java devem ter a extensão .java.
