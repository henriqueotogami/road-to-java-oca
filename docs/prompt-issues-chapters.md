# Prompt para gerar descrição de issue no padrão do capítulo Java OCA

Atue como especialista em educação técnica e certificação Java OCA. Sua tarefa é criar a descrição de uma issue de estudo seguindo exatamente o padrão abaixo, em português, com linguagem clara, profissional e bem estruturada, usando Markdown e emojis sutis.

Objetivo:
- Gerar uma issue de conteúdo didático para um capítulo da trilha Java OCA.
- Manter o mesmo formato visual e organizacional do padrão observado em capítulos anteriores.
- Incluir contexto, objetivos, tópicos abordados, pontos de atenção da prova, proposta de implementação, resultado esperado e checklist final.

Instruções:
- Escreva em português do Brasil.
- Use títulos em português, com foco em Java OCA.
- Mantenha o estilo educativo e técnico.
- Inclua os tópicos relevantes ao assunto do capítulo.
- Sempre mencione que o conteúdo é relevante para a certificação Java OCA.
- No final, inclua um checklist com itens em formato de caixa de seleção.
- Não use frases genéricas demais; seja específico e didático.
- A descrição deve parecer uma issue de backlog de estudo, pronta para ser publicada em GitHub.
